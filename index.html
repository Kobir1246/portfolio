About Me

Computer Science & Engineering Graduate

I'm Shahriar Kobir Sabbir, a Computer Science and Engineering graduate from Daffodil International University. My work spans machine learning, software development, Flutter applications, and hardware-software integrated systems.

My final-year research focused on crop yield prediction using ensemble machine learning techniques. I compared eight regression models, tuned XGBoost to an R² score of 0.836, and used SHAP for model interpretability. Beyond ML, I've built cross-platform Flutter applications and developed embedded systems and assistive technology using Arduino and wireless communication.

I'm particularly interested in software engineering, artificial intelligence, machine learning, robotics, and computer vision. I enjoy exploring new technologies and turning what I learn into practical projects.

Crop Yield Prediction System

A machine learning framework for predicting crop yield across 64 districts in Bangladesh using 5,608 records. Evaluated 8 regression models - tuned XGBoost reached an R² of 0.836, with SHAP used for interpretability and a Flask app for real-time forecasting.

Python XGBoost Scikit-learn SHAP Flask
GitHub

Hand Gesture Controlled Wheelchair

A wireless assistive-mobility prototype: a glove transmitter (Arduino Nano + MPU6050) reads hand orientation and streams commands over 2.4GHz nRF24L01 RF to a wheelchair-mounted receiver (Arduino Uno + L298N) for real-time motor control - built to make mobility more accessible for users with limited fine motor control.

Arduino Embedded C nRF24L01 MPU6050
GitHub

TeamFlow - Project & Team Management App

A cross-platform mobile app for managing projects, tasks, and team members. It includes local notification reminders, a command-based assistant for quick task creation, and offline persistent storage using JSON — with no backend required.

Flutter Dart JSON
